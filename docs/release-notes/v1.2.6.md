# 诊断与修复、OBS 点歌提示与热更新优化

- 新增「诊断与修复」：自动检查弹幕连接、点歌条件、搜索和连接器更新，支持弹幕接收实测、一键修复和实际点歌测试。
- OBS 展示新增点歌结果提示（成功、失败、撤回和主播移出），并可选 Apple Music 动态封面；开启后会向 Apple Music 查询当前歌名与歌手。
- 连接器热更新不再打断直播：网易云运行或点歌正在播放时自动推迟，只自动安装当前播放器的连接器；新版本无法连接时自动回退并暂停该版本。离线时显示上次获取的版本信息，更新时显示下载与安装进度。
- 点歌机更新下载期间可以关闭对话框，重新打开后继续显示进度；下载长时间无进展会提示重试，上次更新未完成时启动后会提醒。
- 设置保存更可靠：切换页面、关闭控制面板或退出前都会先保存；配置文件损坏时自动从备份恢复；运行日志保存在本地，反馈问题时可附带。
- 弹幕连接长时间无数据时自动重连，断网恢复后自动重新连接直播间；队列操作按歌曲确认，避免在队列变化时误删或误切。
- 本机接口只允许点歌机自身窗口进行控制和读取登录、日志等信息，Mod UI 不能再操作点歌机。
- 浅色模式文字更清晰，控制面板空闲时不再反复刷新；安装包体积减小约一半。
