# 诊断与修复、OBS 新提示与更快的更新

- **诊断与修复**：在“运行状态”或“帮助与调试”里一键检查弹幕连接、点歌条件、歌曲搜索和连接器更新，支持弹幕接收实测、自动修复和实际点歌测试。
- **OBS 点歌提示**：内置 UI 新增点歌结果卡片，处理中、点歌成功、失败、撤回和主播移出一目了然；新增“蓝白 · 浅色”“蓝白 · 深色”颜色主题，在“外观设置 → 面向观众 · Mod UI”的“颜色主题”中切换。
- **动态封面**：OBS 展示可选 Apple Music 动态封面；开启后会把当前歌名与歌手发送到 Apple Music 查询，可在外观设置中关闭。
- **更新更快更清楚**：从 1.2.5 升级时只需下载变化的部分，不再每次下载约 160 MB 的完整安装包；下载时可以关闭更新窗口，重新打开后继续显示进度，长时间没有进展会提示重试；重启完成后立即提示更新成功，没装上也会明确告知。
- **连接器更新不打断直播**：网易云正在运行或点歌正在播放时自动推迟更新，只为当前播放器自动安装连接器；新版本连不上播放器时自动回退，并暂停该版本的自动更新。
- **设置与连接更可靠**：切换页面、关闭控制面板或退出前都会先保存设置；配置文件损坏时自动从备份恢复；弹幕连接长时间无数据会自动重连，断网恢复后自动重新连接直播间；队列操作会核对歌曲，避免在队列变化时误删或误切。
- **安全与体验**：本机控制接口只允许点歌机自身窗口使用，Mod UI 和其他网页不能再操作点歌机；浅色模式文字更清晰，控制面板更流畅；运行日志保存在本地，反馈问题时可以附带。

从 1.2.3 或更早版本升级时，旧版本在更新过程中可能会先短暂打开一次窗口，请等待自动重启完成后再使用。
