# 每位观众待播上限与网易云、酷狗队列修复

- **每位观众待播上限**：在“基础设置 → 点歌冷却（秒）与待播上限”中，可以限制每位观众同时在待播队列中的歌曲数。达到上限后，这位观众的“点歌”和“置顶点歌”会失败并说明原因，不扣礼物点歌次数；正在播放的歌不计入，插队点歌、立即点歌和超级用户不受限制。默认 0 为不限制，升级后原有行为不变。游客模式下 B 站通常不提供观众身份，此时无法按观众限制。
- **网易云后续点歌不再卡在等待状态**：修复立即播放已确认后，点歌机仍等待目标开始、导致后续歌曲无法登记为下一首的情况。即使确认时待播队列已空，之后再点歌也会正常登记；已有下一首时，会根据播放器实际队列补插或只重新登记守卫，避免重复插入。暂停自动播放后，目标确认不会继续插入后续歌曲。本次为点歌机本体修复，不包含网易云连接器更新。
- **酷狗不再来回切歌**：酷狗用另一个歌曲编号播放同一首歌时，点歌机按歌名和歌手认出点播歌曲，不再反复切换；播放器始终切不到点播歌曲时最多自动纠正两次，之后保留这首歌在队首，并提示检查播放器版本或更新连接器。
- **支持 64 位酷狗**：酷狗连接器同步更新到 20.1.41.2，能识别 64 位酷狗 20.1.41 的真实版本，不再显示“未知版本”。64 位酷狗暂不支持无切歌插入，会自动改用兼容插入。已安装 20.1.41 连接器的用户会自动收到这次更新。
