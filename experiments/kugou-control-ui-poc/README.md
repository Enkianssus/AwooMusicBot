# 酷狗控制 UI POC

一个独立的 WinForms 调试界面，不修改 BiliNCM-TS 原项目。

## 功能

- 显示酷狗当前歌曲
- 每 250ms 监测状态并接收切歌信号
- 显示稳定的酷狗 `audio_id` 和 `hash`；本地 `SongItem` 仅作为队列项
- 自动重组酷狗窗口标题跑马灯，长歌名滚动不会再触发伪切歌
- 自动检测并用 `WM_CLOSE` 关闭阻塞控制的会员试听弹窗，不移动鼠标
- UI 实时显示“未检测到 / 已检测并关闭 / 已检测但关闭失败”，日志记录宿主句柄、
  嵌入方式和关闭方式
- 切歌事件实时日志
- 纯后台上一首、下一首、播放 / 暂停：不激活酷狗、不移动鼠标、不产生键盘输入
- 纯后台文字搜索并立即播放第一条结果：不激活酷狗、不输入文字、不点击结果
- “强制绕过弹窗点歌”：内部 Stop 后直接用 `dwData=22` 重投点播负载
- 纯后台打开本地音频文件
- 保留 `Alt+Left`、`Alt+F5`、`Alt+Right` 全局快捷键回退
- 上一首、下一首
- 播放 / 暂停切换
- 输入文字后立即搜索并跳转播放第一条结果
- 实验性提交“设为下一首”队列负载（尚未确认当前单曲列表中的实际顺序）

## 启动

先打开酷狗音乐，再运行：

```powershell
dotnet run --project .\experiments\kugou-control-ui-poc
```

或直接运行构建输出：

```text
bin\Release\net8.0-windows10.0.19041.0\KugouControlUiPoc.exe
```

## 调试入口

- `MainForm.cs`：所有 UI 与按钮事件
- `KugouTrackMonitor.cs`：250ms 轮询与 `TrackChanged` 事件
- `KugouNativeController.cs`：链接自控制核心，不复制代码

## 限制

- 纯后台模式使用酷狗 20.0.81 已验证的内部媒体命令：
  `0x40A` 播放/暂停、`0x40B` 上一首、`0x40C` 下一首、`0x40D` 停止。
- 在线点播和本地文件通过酷狗 `Local\KuGouDataExchange` 公布的
  `TaskListener` 消息窗口投递 `WM_COPYDATA`；在线点播固定使用 `wParam=0`
  防止酷狗被激活。
- 普通点播若被会员模态层阻塞，会自动执行一次 Stop + `dwData=22` 重试；
  也可以点击“强制绕过弹窗点歌”直接走这条通路。
- 强制模式只恢复播放器控制，不绕过 VIP/付费授权；搜索结果需要会员且酷狗拒绝播放时，
  UI 会显示 `Privilege` 和明确错误。
- 会员弹窗守卫只处理符合酷狗进程、弹窗尺寸比例、淡黄色页头和橙色付款按钮
  等多项特征的界面；同时扫描额外顶层窗口和主窗口/CEF 子窗口内的嵌入弹层。
- 嵌入弹层关闭采用窗口内定向消息，不移动系统鼠标；消息后会重新视觉检测，
  只有弹层确实消失才显示“已检测并关闭”。
- 手动切换的歌曲会使用完整标题向酷狗搜索元数据做精确匹配；找不到精确结果时
  保持 ID 未解析，不会把相似歌曲的 ID 当成当前歌曲。
- 快捷键回退需在酷狗“设置 → 热键设置”中勾选“启用全局快捷键”。
- 搜索操作使用结果第一条，建议同时输入歌手和歌曲名。
- “设为下一首（实验）”只表示接收端接受了队列负载；在确认酷狗当前队列的插入语义前，
  UI 不会把它报告成已验证成功。
- VIP 歌曲可能只能试听并弹出会员提示；程序不会点击购买或升级。
- 不使用系统全局媒体键，避免误控网易云音乐。
